# E-commerce

The platform includes the following key features:

✅ User Authentication & Role Management
User registration & login
Separate roles for Admin, Businesses, and Customers
Password hashing for security

✅ Product Management
View and search products
Filter products by category
Businesses users can add, update, and delete products

✅ Shopping Cart & Orders
Add products to the cart
Modify cart items (update quantity, remove items)
Place orders

✅ Admin Dashboard
Manage users, products, and orders
View order history

✅ Contact Form Integration
Uses Web3Forms for message handling
Customers can send inquiries directly to businesses
